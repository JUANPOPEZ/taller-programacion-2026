# Programming Workshop 2026

## Project Overview

This repository contains the semester project developed for the Programming Workshop 2026 course at Universidad Manuela Beltrán (UMB). The main objective of this project is to demonstrate the application of object-oriented programming concepts, version control with Git and GitHub, and software development best practices using GitHub Copilot.

The project follows a standard Maven directory structure and has been organized into different layers to improve readability, maintainability, and scalability. The domain package contains the main business entities, while the application and infrastructure packages are prepared for future development as the project evolves throughout the semester.

As part of this workshop, GitHub Copilot was used to generate several Java classes, including an abstract class named **Animal** and its subclasses **Dog** and **Cat**, as well as the **Owner** class. These classes demonstrate important object-oriented programming concepts such as encapsulation, abstraction, inheritance, and polymorphism. The generated code was later reviewed and evaluated according to the SOLID principles and the recommendations described in the book *Clean Code* by Robert C. Martin.

This repository also includes the necessary configuration files for Java development, such as `.gitignore` and `build.gradle`, allowing the project to be easily managed and extended in future activities.

Git is used as the version control system to track changes throughout the development process, while GitHub provides an online platform for collaboration, repository management, and project documentation.

The purpose of this repository is not only to store the project source code but also to document the learning process, the use of artificial intelligence tools during software development, and the implementation of programming best practices. Future updates will include additional classes, improved functionality, testing, and new features as required by the course.
